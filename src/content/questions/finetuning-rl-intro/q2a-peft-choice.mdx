You must fine-tune a **7B** model on a single **12 GB** consumer GPU. Which
approach fits?

<Rationale title="Why">
**QLoRA.** A 7B full fine-tune needs ~60 GB — gradient checkpointing trims
*activation* memory but not the optimizer states that dominate, so it still won't
fit 12 GB. fp16 LoRA freezes the base but still loads it in 16-bit (~16 GB). The
int8-base option is closer but the established sub-16 GB recipe is QLoRA's 4-bit
NF4 base (~6 GB) with minimal quality loss. QLoRA is the standard answer for
single-consumer-GPU fine-tuning.
</Rationale>
