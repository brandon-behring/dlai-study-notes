A deployed model starts returning answers in the wrong JSON shape for a new request type.
Following the intervention framework, what do you reach for first?

<Rationale title="Why">
The framework says try the **fastest** intervention that could work first: a formatting problem
is the canonical prompt-engineering fix (~1 day, no new data), so you start there and escalate
only if it fails or the pattern proves systemic. SFT and RL are week-scale interventions for
*consistent behavior* and *quality* respectively — overkill for a format bug — and retraining
from cold-start throws away everything to fix a template.
</Rationale>
