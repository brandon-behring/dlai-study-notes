What is the correct order of the Phoenix Experiments pipeline?

<Rationale title="Why">
You first build the **dataset** of test cases, define a **task** that runs the agent on one
row, **run the experiment** to execute that task over the whole dataset, then apply
**evaluators** to score the results — the agent analogue of cases → test function → run →
assertions. The other orders invert that dependency: you can't write evaluators or run an
experiment before the dataset and task exist, and evaluators score results, so they come last.
</Rationale>
