answer: >
  An AI agent is a software system that takes actions on a user's behalf using reasoning. Its
  three core capabilities are reasoning (the LLM decides what to do), routing (selecting which
  tool or skill to call), and action (executing the tool), looping on the result. What
  distinguishes it from a fixed prompt chain is that the agent decides *what to do next* at
  run time, rather than following a predetermined sequence of steps. Common wrong answer: "an
  agent is any application that calls an LLM" — that conflates an application with an agent;
  without run-time routing and decision-making it is a fixed application, not an agent.
