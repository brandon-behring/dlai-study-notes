Your dashboard reports the agent is 92% accurate — but that number comes from an LLM judge.
What must you do before trusting it?

<Rationale title="Why">
The 92% is the judge grading itself, which is circular: if the judge is only 75% accurate, the
number is noise. Meta-evaluation compares the judge's labels against a code-based ground-truth
reference and reports the agreement rate — the independent check the dashboard lacks. A bigger
dataset reduces variance but not the judge's bias; numeric scoring makes calibration *worse*;
and averaging several uncalibrated judges still gives you no ground truth.
</Rationale>
