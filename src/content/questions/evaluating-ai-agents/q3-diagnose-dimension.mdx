answer: >
  Compare the trace against the ground-truth label on both dimensions separately. First check
  the chosen tool against the expected tool: if it differs, it's a tool-selection failure. If
  the tool matches, inspect the extracted arguments against the expected parameter values: a
  mismatch there is a parameter-extraction failure. Confirm by re-running a few near-identical
  queries where only the tool-ambiguity (or only the parameter difficulty) varies — if failures
  track the parameter variation while the tool stays correct, it's parameter extraction. The
  router's two-dimension breakdown is exactly what makes this attribution possible from the
  trace. Common wrong answer: "the answer was wrong, so the router failed" — that doesn't say
  *which* dimension; you must check tool and parameters separately.
