What distinguishes a golden dataset from a general evaluation dataset?

<Rationale title="Why">
A golden dataset is the *shipping gate*: every row is a must-pass scenario, it codifies known
failure modes from past bugs, it grows as new failures appear, and a regression on it blocks
the merge. It is deliberately small and critical, not an attempt to cover every input (that
would be too slow to gate on). It composes code-based and LLM-judge evaluators as appropriate,
and far from frozen, it must evolve — a golden set that never changes goes stale and stops
catching new regressions.
</Rationale>
