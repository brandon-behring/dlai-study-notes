You have four LLM features. Which one is an *agent* rather than a fixed LLM application?

<Rationale title="Why">
The distinguishing mark of an agent is **run-time reasoning about what to do next** — the
system that chooses among searching, querying, or answering, and then routes based on the
result, is making routing decisions an application doesn't. The single-call summariser and
the email classifier are one-shot LLM calls with no routing. The RAG pipeline runs a
*predetermined* retrieve-then-generate sequence — useful, but the path is fixed in advance,
so it is an application, not an agent.
</Rationale>
