In a self-improving pipeline, the automated eval score rises while user-survey satisfaction
falls. What most likely happened?

<Rationale title="Why">
The eval dataset and few-shot examples are built from user feedback; when that feedback is
noisy, the *evaluator* learns from the same poison, so its score climbs as quality drops — the
metric self-confirms the degradation. The independent survey is the trustworthy signal here,
not the biased one. The agent didn't genuinely improve (the survey says otherwise), and golden
dataset size affects run time, not whether the automated score diverges from reality.
</Rationale>
