Why are collected traces called the "bedrock for evaluation at scale"?

<Rationale title="Why">
Each trace stores full inputs, outputs, and intermediate steps, so automated evaluators can
score thousands of real runs and compare across versions — that is what "at scale" means. The
value isn't compression or storage savings; traces don't make a non-deterministic agent
deterministic; and they complement, rather than replace, a curated test dataset (you still
need known-answer cases for some checks).
</Rationale>
