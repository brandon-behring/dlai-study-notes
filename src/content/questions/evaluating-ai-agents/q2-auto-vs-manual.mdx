You add automatic instrumentation to your OpenAI client and see every LLM call, but the
router's decisions stay invisible. Why?

<Rationale title="Why">
Automatic instrumentation hooks the model API client, so it captures model calls but not your
router, which is ordinary orchestration code rather than an API call — that gap is exactly what
manual spans fill. It does not hide LLM calls (it surfaces them), the router isn't dropped for
running elsewhere, and routers aren't excluded for being deterministic — an LLM-based router
isn't deterministic in any case.
</Rationale>
