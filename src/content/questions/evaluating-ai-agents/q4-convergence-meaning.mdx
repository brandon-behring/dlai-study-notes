A convergence score of 1.0 tells you that…

<Rationale title="Why">
Convergence measures *consistency* — the fraction of runs on the minimum-step path — so 1.0
means the agent always takes the same shortest path it found, which could be a consistently
wrong one. It says nothing about correctness or answer quality, so neither the "correct on
every query" nor the "maximal quality" reading holds. And the minimum is relative to the runs
observed, not a theoretical optimum — universal waste sits inside that minimum undetected.
</Rationale>
