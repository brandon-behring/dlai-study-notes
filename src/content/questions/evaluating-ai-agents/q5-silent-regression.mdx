Which production failure will latency and error-rate dashboards fail to catch?

<Rationale title="Why">
A silent regression produces wrong-but-plausible output without any error or slowdown — so
latency and error-rate stay green and nothing fires; only content-quality monitoring
(evaluator scores over live traces, provenance checks) detects it. The other three all move a
*system* metric a standard dashboard already watches: timeouts and crash loops spike the error
rate, and a model-swap slowdown spikes latency.
</Rationale>
