A single model call runs inside a tool that the router selected. From outermost to innermost,
how do the OpenInference span kinds nest?

<Rationale title="Why">
The outermost unit is the whole run (Agent), then the router iteration that chose the tool
(Chain), then the tool invocation (Tool), then the model call inside it (LLM). The orderings
that place LLM or Chain outermost invert containment — the model call is the innermost unit and
the agent run is the root. The variant that buries Chain beneath Tool misorders routing and
execution: the router decides *before* the tool runs.
</Rationale>
