answer: >
  Four steps. (1) Question — the user asks in natural language. (2) Generate — the LLM writes Cypher
  from the injected schema and few-shot examples. (3) Execute — Neo4j runs the generated query. (4)
  Answer — the LLM synthesises the returned rows into a natural-language reply. The chain
  (GraphCypherQAChain) needs the schema and a good few-shot prompt for reliable generation, and
  should validate the query before executing in production. Common wrong answer: putting execution
  before generation, or assuming it is vector retrieval — this pipeline generates and runs Cypher,
  it does not embed and search.
