Creating a full-text index on manager names is which phase of Extract-Enhance-Expand?

<Rationale title="Why">
Adding an index (or computed property) to nodes that already exist is the **Enhance** phase —
like vector embeddings or geospatial points. Extract *creates* the nodes, Expand *connects* them
with relationships, and validation isn't one of the three phases.
</Rationale>
