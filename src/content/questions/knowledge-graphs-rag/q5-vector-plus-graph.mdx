In the NetApp example, what did adding a chunk window reveal that single-chunk retrieval missed?

<Rationale title="Why">
The single best-matching chunk gave the high-level answer ("enterprise storage and data
management"); the window followed NEXT into the adjacent chunk and surfaced the specific Keystone
product detail. Vector search found the entry point, graph traversal added the surrounding
context — the window does not change the score, add a model, or speed anything up.
</Rationale>
