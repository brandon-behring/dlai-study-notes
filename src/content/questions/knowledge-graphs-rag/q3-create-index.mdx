answer: >
  `CREATE VECTOR INDEX chunk_embeddings IF NOT EXISTS FOR (c:Chunk) ON (c.textEmbedding) OPTIONS
  {indexConfig: {`vector.dimensions`: 1536, `vector.similarity_function`: 'cosine'}}`. The
  dimension (1536) must match the embedding model's output exactly, and `cosine` is the
  recommended similarity function for OpenAI embeddings. `IF NOT EXISTS` makes creation
  idempotent. It is ready to query when `SHOW INDEXES` reports its status as **ONLINE** — while
  it is `POPULATING`, searches return incomplete or empty results. Common wrong answer: querying
  immediately after creating it — you must wait for ONLINE, or the results are wrong.
