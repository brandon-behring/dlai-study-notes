Why pass an API key into a Cypher query as a parameter (`$openAiApiKey`) rather than an f-string?

<Rationale title="Why">
A parameter keeps the secret out of the query string — so it can't leak into logs, error
messages, or the query cache, and there's no injection surface — and it lets Neo4j reuse a
cached execution plan across calls. Typing speed is irrelevant; you should *not* store API keys
in the graph; and you technically *can* build a query string with interpolation (that's exactly
the unsafe thing to avoid), so it isn't that Cypher forbids it.
</Rationale>
