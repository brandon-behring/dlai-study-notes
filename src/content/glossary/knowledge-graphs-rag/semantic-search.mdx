Retrieval by **meaning rather than exact words**: encode the query and the corpus into the same
embedding space and rank by similarity, so "movies about love" matches a tagline that never
contains the word "love." It is the capability a vector index adds to the graph — and it
complements (does not replace) graph traversal, which finds *connected* entities rather than
*similar* text.
