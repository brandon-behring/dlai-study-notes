A version of the agent differing by **one** of the five improvement levers — prompt, tool
definitions, router logic, skill structure, or model selection. The discipline is to change
*one lever at a time*: alter the prompt and the model together and you can't attribute the
result to either. Variants are compared head-to-head in an experiment.
