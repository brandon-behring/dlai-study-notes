term: LLM System Evaluation
aliases: [system eval, end-to-end evaluation]
domain: eval-foundations

tags: [evaluation]
---

Evaluation of your **entire application's end-to-end performance** on real-world,
domain-specific data. It answers the question that matters — "does my system solve the
user's actual problem?" — and must be re-run on every prompt or code change, because any of
them can regress it. Its main cost is curating representative test data; the practical move
is to start with a small synthetic test set and grow it as real traffic arrives.
