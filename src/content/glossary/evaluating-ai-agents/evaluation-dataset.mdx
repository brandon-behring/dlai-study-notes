A structured collection of test cases with **input keys** (forwarded to the agent) and
**output keys** (forwarded to evaluators for comparison). Built to be "comprehensive, not
exhaustive" — 1–2 cases per input type — and fed from three sources: manually constructed (edge
cases), model-generated (coverage), and production-sampled (highest ecological validity).
