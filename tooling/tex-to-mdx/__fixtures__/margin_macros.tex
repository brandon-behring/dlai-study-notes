\interviewmargin{``How do Knowledge Graphs improve RAG beyond vector search?''
is a common system design question for MLE and DS roles.}

\warningmargin{Vector search finds \emph{similar} text; KG traversal finds
\emph{connected} entities.}

\crossrefmargin{vol6 Ch 4: RAG --- KG traversal as a retrieval strategy
that complements embedding-based similarity search.}

\patternmargin{The course builds on this insight progressively: M3 adds
vector search, M5 adds graph traversal, M7 combines both.}

\formulamargin{Graph traversal cost: $O(k^d)$ where $k$ = avg connections/node,
$d$ = traversal depth.}

\practicemargin{The SEC filing dataset used in this course (Modules 4--7)
contains real Form 10-K and 13 filings.}
